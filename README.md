# Amazon Clone

A beginner-friendly Amazon homepage clone built with **HTML** and **CSS**.

This is my first hard-coded web development project. I created it to practice how real websites are structured, how layouts are built with CSS, and how different sections of a page work together.

## About This Project

This project is a static front-end clone of an Amazon-style homepage. It includes a navigation bar, search bar, hero section, product category boxes, recommendation section, and footer.

The main goal of this project was learning, not building a fully working e-commerce website. The buttons, search bar, cart, and links are only for design practice and do not have JavaScript functionality yet.

## What I Used

- **HTML5** for the page structure
- **CSS3** for styling and layout
- **Flexbox** for arranging navbar, panels, product cards, and footer sections
- **Font Awesome** for icons like search, cart, menu, and location
- **Local images** for the logo, hero banner, and product category images
- **VS Code / browser** for writing and testing the project

## Features

- Amazon-style top navigation bar
- Logo section
- Delivery location section
- Search bar with category dropdown
- Sign-in and orders area
- Cart icon
- Secondary navigation panel
- Hero banner image
- Product shopping cards
- Personalized recommendation strip
- Footer with multiple link columns
- Hover effects on navbar and panel items

## How To Run This Project

You do not need to install anything special because this is a static HTML and CSS project.

### Option 1: Open Directly In Browser

1. Download or clone this project.
2. Open the project folder.
3. Double-click `index.html`.
4. The Amazon clone homepage will open in your browser.

### Option 2: Run With VS Code Live Server

1. Open the project folder in VS Code.
2. Install the **Live Server** extension if you do not already have it.
3. Right-click on `index.html`.
4. Click **Open with Live Server**.
5. The project will open in your browser with a local development URL.

## Important Note

The main file name is:

```text
index.html
```

This name is useful because many hosting platforms automatically look for an `index.html` file as the homepage.
